## 下載與記憶體

年度 CSV 合計 30.79 MiB，gzip 合計 9.72 MiB。gzip 解壓後與 CSV 完全相同，SHA-256 正確。支援瀏覽器優先載入 gzip，不支援 DecompressionStream 時使用 CSV。
Worker 只保留期間與暖機所需日線，不保留多輪年度物件快取。一年預設參數保留 581,390 筆；本機瀏覽器載入與解析 0.60 秒、計算 1.17 秒，這是本機測試，不代表行動網路下載時間。
桌面 Node 驗證一年預設參數：heap 185.2 MiB、程序最高 RSS 261.6 MiB；最高 120 日長均線：heap 203.7 MiB、程序最高 RSS 285.8 MiB。這是桌面程序量測，不是手機實機記憶體。
模擬手機 390×844 視窗（內容寬 375px，含捲軸）：整頁 scrollWidth 與 clientWidth 相同，沒有整頁橫向溢出；圖表與表格在各自容器捲動。沒有實機手機可量測 RAM、低記憶體終止與行動網路表現，仍需在實際裝置驗證。

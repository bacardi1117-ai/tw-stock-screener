# 技術面歷史回測第一版規格

## 資料與範圍

- 僅使用本地 `data/prices/YYYY.csv` 已保存的普通股日線。公開檔只含日期、代碼、開高低收與成交股數；名稱與市場來自公開股票清單。沒有 API、最新財報、QGM 或策略 A–E 輸入。
- 成交量單位為「股」，整張交易單位為 1,000 股。現股做多，不融資、不放空，不買進已持有股票。
- 涵蓋期間、交易日與扣除 120 個交易日暖機後的可回測起日均來自 manifest，不硬編碼。最近一年從截止日往前一個日曆年之後的第一個已確認交易日開始；該日起日前須有至少 120 個交易日的市場資料。個股仍須通過連續有效行情檢查。股票清單為目前清單，存在存活者偏誤。價格未除權息調整，結果是未含息價格回測，不是含息總報酬；設定頁與結果頁都須說明。

## 訊號、委託與帳戶

1. 全部指標只讀當日及更早資料。短／長均線與均量需 N 個連續市場交易日有效日線；N 日報酬需 N+1 個。回測起日前資料僅供暖機；不足時不得產生訊號，分別記錄暖機不足與日線缺資料。
2. 每個收盤後依當時資訊產生買進訊號，按使用者選定的排序方式及代碼決定性排序。只在**下一個市場交易日**的開盤嘗試買進；未成交即取消，不順延。最後一日訊號不下單。
3. 訊號日晚以當時現金按剩餘持股名額等分配置，依當日收盤估算整張數量。開盤執行買單時，依實際開盤價、滑價及買進手續費，縮減為可買的整張數；不足一張才取消。對同一開盤，先固定排序處理舊出場，再依前晚排名處理買單；所有買單只可使用該開盤前已可用的現金，該開盤賣出所得從下一交易日起可再投入。扣款依排名依序進行，不允許現金為負。
4. 停利與停損為持股期間每日有效的出場意圖。開盤穿越門檻按開盤價；否則日高低價觸及時按門檻價，兩者均計不利滑價。日線同時觸及停利、停損時先停損。因停牌、缺日線或疑似鎖死跌停無法賣出時，保留出場意圖，下一可交易日繼續嘗試；不可清掉出場狀態。停利、停損不設定單日到期。
5. 最長持有日以市場交易日計。到期當晚產生下一交易日開盤賣出委託；若未成交，轉為持續有效的到期出場意圖，直到可成交或回測結束。出場意圖優先於新的停利／停損判定，原因保留最早觸發類型。期末不強制平倉。
6. 股票當日缺日線、開盤價或成交量為零時不成交。疑似單價鎖死漲停不買，疑似單價鎖死跌停不賣；以與前收約 10% 價差及開高低收同價作近似判定，揭露無委託簿與正式漲跌停旗標的限制。持股缺日線時按最後可用收盤價估值並標示價格過期。
7. 買進每筆收取 `max(成交金額 × 費率, 最低手續費)`；賣出再扣手續費及賣出稅。滑價使買價提高、賣價降低。費率、最低手續費與滑價是可調的模擬假設，預設值不得標示為實際券商費率。

## 結果

- 每日淨值序列以初始資金為第 0 點，之後為可用現金、待次日可用賣款及持股按當日最後可用價估值之和。最大回撤包含初始資金。累積報酬以期末淨值對初始資金計；年化報酬按實際日曆天數計。
- 交易勝率與平均獲利／虧損只計扣除交易成本後的已平倉交易。沒有已平倉交易時顯示「無已平倉交易」，不可顯示 0% 或 NaN。
- 結果包含有效日期、未平倉與其估值日期、逐筆交易與 CSV 下載，以及暖機不足、缺資料、無法成交、資金不足等跳過／未成交原因統計。不顯示虛構的大盤基準。

## 官方行情續抓與效能

- `python src/backtest_history.py --start YYYY-MM-DD --end YYYY-MM-DD` 以 TWSE MI_INDEX、TPEx dailyQuotes 全市場日資料逐日期／來源抓取，每次嘗試後至少間隔一秒，沿用有限次重試與退避；遇 429 或重試耗盡即停止。這是獨立手動工具，不呼叫 FinMind，也不變更財報排程。原本 `market-history` 的每輪 36 日上限維持原設定。
- `data/state/price_history_progress.json` 記錄每個日期／來源；原始正規化日檔存於 `data/prices/.backtest_history/`，成功後立即保存，續跑跳過已完成來源。獨立 OS lock 防止重複行情程序；中斷後已成功日期仍可合併及續跑。
- 歷史資料按當時官方報價涵蓋目前清單中的代碼，可跨市場轉板。年度檔以日期／代碼去重，保留原有有效數值，新增缺漏，僅用官方有效資料修復無效列；來源衝突留在稽核紀錄。不填造上市前、停牌、缺報價或無交易價格。
- 無資料日僅記為官方來源未回傳市場列。個股首次／最後觀測報價不代表確認上市／下市日；區間內缺價可能是停牌、無成交或來源缺漏，未查證不得直接標為新上市。
- 精簡年度 CSV 與 gzip 版本只包含日期、代碼、OHLCV；manifest 記錄筆數、大小與 SHA-256。支援 DecompressionStream 的瀏覽器優先載入 gzip，否則使用 CSV。Worker 依選定日期與指標暖機篩選日線，不保留歷次年度物件快取；結果顯示載入、計算時間和檔案下載量。
- 行情資料會隨補抓改善。同參數回歸需比較已保存的基準交易、淨值與回撤，並說明新增官方資料造成的差異。合成測試仍檢查交易規則；實機手機記憶體上限需在使用者裝置另行驗證，桌面測量不能冒充實機數據。

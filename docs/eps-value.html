STRATEGY CONTROLS

策略條件

完整年度 EPS

比較最新連續兩個可用完整年度；只用基本 EPS，不使用預估值。

低本益比

使用 TWSE / TPEx 已發布的最新有效 PER 來源值，不以年度 EPS 重算。

回測月線與乖離

乖離率 =（收盤價 / 月線 − 1）× 100%。

從上方回落

檢查前 N 個交易日，是否至少一天收盤價高於當日月線設定百分比。

月線上揚（可選）

當日月線須高於指定交易日前的同週期月線。
